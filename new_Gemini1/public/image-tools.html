SD พร้อมนำไปเปิด Pi

  1. ถอด SD อย่างปลอดภัย แล้วใส่ Raspberry Pi
  2. ต่ออินเทอร์เน็ตและเปิดเครื่อง รอติดตั้ง ROS และเครื่องมือประมาณ 20–60 นาที
  3. Pi จะรีบูตเมื่อติดตั้งเสร็จ แล้วจึงเพิ่มหุ่นใน ROSIDE
ตรวจสถานะบน Pi / แก้ไขเมื่อติดตั้งสะดุด

สถานะพร้อมใช้: /boot/firmware/ROSIDE.ENV แสดง ready

ดูบันทึก: sudo tail -f /var/log/roside-environment.log

ติดตั้งต่อ: sudo python3 /opt/roside-env/install_env.py

Image อยู่บนคอมของคุณ · Pi ต้องต่ออินเทอร์เน็ตในการบูตครั้งแรกเพื่อติดตั้ง ROS
