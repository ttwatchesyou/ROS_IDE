ดาวน์โหลด ROS Project ทั้งหมด
ZIP จะรวม source packages ทั้ง workspace, Robot Config, Maps, mecha_rayong_nav, ตัวติดตั้ง และคู่มือใช้งานจริง

    

    

      
🧩 src/ ทั้งหมดRobot Model, TF, Odom, MapSim และทุก package ในโปรเจกต์

      
🗺 maps/ + map.jsonSaved Maps และสนามจาก Map Editor

      
🚀 mecha_rayong_navParameters และ launch สำหรับ Navigation บนหุ่นจริง

      
🛠 Installer + Guideinstall_project.sh, install_lidar_driver.sh และ INSTALL_PROJECT.md

    

    
1. ติดตั้ง Packages ที่จำเป็น

    
bash install_project.sh

    
2. แตก ZIP ลงใน ros2_ws/src แล้ว Build

    
cd ~/ros2_ws && colcon build --symlink-install --packages-select mecha_rayong_nav && source install/setup.bash

    
3. เปิด Driver หุ่นก่อน แล้วเริ่ม Navigation

    
ros2 launch mecha_rayong_nav navigation.launch.py use_sim_time:=false

    
⚠️ หุ่นยนต์จริงต้องมี /scan, /odom, /tf และรับคำสั่ง /cmd_vel พร้อม TF: map → odom → base_link → laser_frame
